## 🎨 UI Library

Our UI library is our go to way to building web applications. More than a collection of components, it is a all-in-one startup package that helps us build web applications faster and with less effort.

As of currently it is only intended to work with Next.js, there are no immediate plans to support other frameworks.

The main objective of `@tmlmobilidade/ui` is to provide a plug and play start to building web applications.

## 🚀 Features

The components are based on the [Mantine](https://mantine.dev/) library and are styled with the TML design system.
